离线账本查看器
2026-11-07

分工
  项目根目录的 main.py 启动桌面管理端，可维护条目、加密密码、保存和复制账本。
  网页可打开或粘贴账本、浏览公开资料、逐条解密密码和下载账本副本。

使用
  1. 用浏览器打开项目根目录的 password_viewer.html。
  2. 点击“打开账本文件”，选择 .vault 或 .txt。也可在桌面管理端打开“编辑账本文本”，全选并复制，再粘贴到网页并点击“读取粘贴内容”。
  3. 输入管理密码，点击“验证密码”。验证成功后，管理密码输入框会收起。选择条目即可解密，已选中的条目会在验证成功后解密。
  4. 条目密码默认隐藏。勾选“显示密码”查看，或直接点击“复制密码”。展开“公开资料和加密参数”可查看该条的其他资料。
  5. 点击“下载账本副本”，浏览器会下载账本.txt。打开文件时保留原始字节，粘贴内容以 UTF-8 保存。下载副本只包含密码密文和公开资料。
  编辑粘贴内容后，请重新点击“读取粘贴内容”。点击“清空页面”可以清除当前账本和密码，原文件仍可从本机打开。
  格式 3 使用账本头的加密校验样本验证管理密码，再逐条验证和解密密码。校验样本可用于验证空账本。
  格式 1 和格式 2 没有校验样本。查看器会用所选已加密条目验证，未选中已加密条目时则使用首个已加密条目。旧账本可以点击“换用管理密码”。
  条目详情会显示该条的加密算法、内存、迭代次数和并行通道数。

只携带一个 HTML
  password_viewer.html 内含页面、JS 算法、Wasm 核心和标准 C 支持组件的许可通知。
  单独复制这个文件就可以运行，无需旁边的源码目录、服务器、联网下载或额外加密库。
  程序不使用 localStorage、sessionStorage、Cookie 或数据库保存账本、管理密码、明文或派生密钥。
  网页通过内容安全策略禁止网络请求；应用没有网络调用。
  浏览器无法自动复制时，勾选“显示密码”后手动复制。密码已显示时，再点击“复制密码”会选中条目密码。
  公开备注与其他条目资料均可直接读取。复制的内容由系统剪贴板保留。

计算边界
  读取、解析、搜索账本只处理公开内容。点击“验证密码”或在管理密码框按 Enter 时才验证。
  验证成功后按需解密当前条目。切换条目会清空上一条解密结果，不会批量解密。
  每次计算独立实例化同一份自写 C 编译的 Wasm；管理密码在当前账本栏保留，派生密钥不缓存。
  页面主线程顺序完成计算，计算前刷新状态并禁用相关操作，完成后恢复；没有 Worker 或后台任务。
  默认保持64 MiB，不为了手机速度自动降低参数。高于默认规模的记录在计算前询问是否继续。
  Wasm产物的线性内存总上限为128 MiB，超出能力的条目会明确报错，可在PC端查看。
  实例结束后由浏览器管理回收；清空界面不构成可靠内存擦除保证。

兼容性与历史验证（2026-10-27）
  浏览器需支持WebAssembly、BigInt、TextEncoder/TextDecoder等现代JS能力。
  Argon2重计算使用Wasm；Poly1305/GHASH的少量多精度运算使用JS BigInt。
  支持AES-256-GCM、ChaCha20-Poly1305、XChaCha20-Poly1305，与PC现有载荷格式一致。
  UTF-8输入保留原始空白、中文和Unicode，不做密码归一化；解密后的BOM也保留。
  可读取格式 1、2 和 3 的账本及可选备注。格式 2 从账本头解析内存和迭代次数。格式 3 仍在每条中保存加密参数。
  Windows / i5-14400：Edge122、Chrome156离线上真实执行，每条完整解密约0.14秒。
  两个浏览器都验证了读取不解密、按条解密、切换清空、空密码、错误管理密码、改密文、文件读取、剪贴板与回退、DOM注入防护。
  HTTP(S)请求为0，脚本错误为0，localStorage/sessionStorage为空。
  桌面和390px布局已实际截图检查；390px布局测试不代表Android真机运行测试。
  用户此前报告旧手机测速页20次64MiB派生共9.27秒；该成绩不是本查看器的真机解密成绩。
  未进行Android真机测试，也不声称完整密码学安全审计或恒定时间实现。

源码与测试
  page.template.html：界面和样式模板。
  gui.js：读取和下载账本、选择条目、解密密码、清空页面和复制密码。
  core/text_decoder.js：与PC一致的文本规则及公开字段校验。
  core/process.js：文本参数 -> Argon2 -> 认证解密 -> 密码长度和 UTF-8 检查。
  core/ciphers.js：自写的三种认证解密算法。
  core/argon2id.wasm：已有自写C核心的编译产物；共用源码在 ../core/argon2id.c 和 ../core/argon2id.h。
  core/BUILD.txt 保存准确编译记录及重编译路径。
  build.py：Python标准库把上述文件合成为项目根目录的单个HTML，开发时运行即可，使用者无需Python。
  node test/test_ciphers.cjs：7个固定向量、228组Python对照、1125个篡改拒绝。
  2026-10-27 开发时另进行了152组Node/OpenSSL独立对照，通过。
  node test/test_text.cjs：严格文本规则、备注、中文、惰性派生、原账本与三算法跨语言解密。
  node test/test_handoff.cjs：使用实际PC GUI“复制全部”得到的文本，逐条核对四个完整参数样本。
  node test/test_gui_session.cjs：在 DOM 替身中运行构建后的 HTML 和真实 Wasm，验证格式 3 校验样本、旧格式回退、按条解密、遮罩和原字节下载。
  test目录中的虚构样本、测试凭据和测试源码不嵌入正式HTML。
